\#\# Brand & Style

&nbsp;

This design system delivers an operational review platform tailored for Thai content creation workflows, digital marketing agencies, and corporate editorial teams. Drawing aesthetic ethos from modern developer and issue-tracking platforms like Linear and Notion, the system rejects ornamental skeuomorphism in favor of structural clarity, dense typographic utility, and razor-sharp feedback loops.

&nbsp;

The brand persona is analytical, decisive, and calm. Reviewing dense Thai copy requires absolute visual cleanliness to avoid visual fatigue; consequently, the canvas is dominated by structured neutral surfaces, explicit boundary lines, and contextual semantic badges. The atmosphere evokes immediate command over approval pipelines, versioning diffs, and cross-channel publishing schedules without friction.

&nbsp;

\#\# Colors

&nbsp;

The color architecture relies on a surgical neutral baseline with high-contrast functional color assignments. Backgrounds utilize pure \`\#FFFFFF\` layered over subtle \`\#F8FAFC\` slate canvas tinting, framed by crisp \`\#E2E8F0\` hairline dividers.

&nbsp;

Primary text is rendered in rich charcoal \`\#0F172A\` with secondary metadata in \`\#334155\` and \`\#64748B\`, maintaining WCAG AAA legibility across complex glyph accents.

&nbsp;

Semantic review states are strictly codified:

\- \*\*Pending Review (รอตรวจ):\*\* Amber \`\#D97706\` text over \`\#FEF3C7\` container with \`\#FDE68A\` border.

\- \*\*Changes Requested (ขอแก้):\*\* High-priority Rose/Red \`\#E11D48\` text over \`\#FFE4E6\` container with \`\#FECDD3\` border. Demands immediate visual prioritization.

\- \*\*Approved (ผ่าน):\*\* Emerald \`\#059669\` text over \`\#D1FAE5\` container with \`\#A7F3D0\` border.

\- \*\*Published (ลงแล้ว):\*\* Indigo \`\#4F46E5\` text over \`\#EEF2FF\` container with \`\#C7D2FE\` border.

\- \*\*Draft (ร่าง):\*\* Slate \`\#475569\` text over \`\#F1F5F9\` container with \`\#CBD5E1\` border.

&nbsp;

Entity tags feature dedicated taxonomy:

\- \*\*FutureSkill:\*\* Indigo \`\#4338CA\` on \`\#EEF2FF\`

\- \*\*SkillPass:\*\* Teal \`\#0F766E\` on \`\#CCFBF1\`

\- \*\*Facebook:\*\* Blue \`\#1D4ED8\` on \`\#EFF6FF\`

&nbsp;

\#\# Typography

&nbsp;

IBM Plex Sans provides the typographic foundation across all weights. The choice directly resolves common legibility degradation in bilingual Thai-English workspaces. Thai vowels and tone marks require expanded line-height parameters compared to Latin scripts; consequently, all body lines scale at a minimum of \`1.6x\` to \`1.75x\` the font size to prevent overlapping tone marks (ไม้เอก, ไม้โท) and diacritics.

&nbsp;

Headlines employ medium and semi-bold weights without excessive tracking to maintain solid mechanical rhythm. Captions and social copy preview modules adopt \`body-lg\` (\`16px / 28px\`) to ensure editorial reviewers assess real-world readability effortlessly. Monospaced and micro labels adopt tabular lining figures to maintain column alignment across numeric revision timestamps.

&nbsp;

\#\# Layout & Spacing

&nbsp;

The layout model implements a fluid 12-column workspace flanked by a fixed 240px utility sidebar and contextual side-drawer inspectors (380px fixed width).&nbsp;

&nbsp;

\- \*\*Density Structure:\*\* The system prioritizes Linear-style modular panes. Grid gaps and list insets use rigid multiples of 4px.

\- \*\*Desktop (1280px+):\*\* Tri-pane layout featuring global channel navigation, main caption review stream, and real-time editorial feedback/version timeline. Gutter is set to 24px (\`1.5rem\`), outer margins to 32px (\`2rem\`).

\- \*\*Tablet (768px \- 1279px):\*\* Sidebar collapses into an icon rail (64px width), while the version timeline docks into an expandable overlay panel.

\- \*\*Mobile (\<768px):\*\* Single-column stacked cards with bottom-sheet modals for status switches and revision comments. Padding normalizes to 16px (\`1rem\`).

&nbsp;

\#\# Elevation & Depth

&nbsp;

Visual hierarchy is maintained through precision outlines and crisp tonal surfaces rather than heavy blur shadows.

&nbsp;

\- \*\*Base Layer (Surface 0):\*\* \`\#F8FAFC\` canvas representing the application backdrop.

\- \*\*Panel Layer (Surface 1):\*\* \`\#FFFFFF\` cards, sidebars, and toolbars bounded by a solid 1px \`\#E2E8F0\` border.

\- \*\*Interactive Hover Layer:\*\* Shifts background to \`\#F1F5F9\` with a subtle elevation key light: \`0 1px 2px 0 rgba(15, 23, 42, 0.05)\`.

\- \*\*Flyout & Dropdown Layer (Surface 2):\*\* Context menus, popovers, and status selectors use \`\#FFFFFF\`, a 1px \`\#E2E8F0\` boundary, and a targeted ambient drop shadow: \`0 10px 15px \-3px rgba(15, 23, 42, 0.08), 0 4px 6px \-4px rgba(15, 23, 42, 0.03)\`.

\- \*\*Active Focus / Diff Accent:\*\* 2px focus ring using \`\#4F46E5\` with 15% opacity halo for keyboard navigation.

&nbsp;

\#\# Shapes

&nbsp;

With a roundedness index of \`1\`, UI elements embrace a sharp, disciplined, semi-technical geometry. Base containers, input boxes, status chips, and table cells utilize \`0.25rem\` (4px) corner radii, reflecting an engineered productivity apparatus.&nbsp;

&nbsp;

Card containers, split diff panes, and side flyouts scale up to \`0.5rem\` (8px) using \`rounded-lg\` tokens, while standard modal viewports cap at \`0.75rem\` (12px) \`rounded-xl\`. Avatars and single-character status pins remain fully circular (\`9999px\`) to cleanly contrast against rectilinear text grids.

&nbsp;

\#\# Components

&nbsp;

\#\#\# Buttons & Action Controls

\- \*\*Primary Action (Approve / Submit):\*\* Filled \`\#4F46E5\` background, \`\#FFFFFF\` text, \`rounded\` (4px), 36px height, \`label-md\` weight. Hover: \`\#4338CA\`.

\- \*\*Urgent Rejection (ขอแก้):\*\* Outlined or tinted filled button using \`\#E11D48\` on \`\#FFE4E6\` with crisp 1px border \`\#FECDD3\`. Prominently exposed in the action header to prevent accidental approval.

\- \*\*Ghost/Tertiary:\*\* No background, \`\#334155\` text, 1px transparent border, hovering to \`\#F1F5F9\`.

&nbsp;

\#\#\# Chips & Status Badges

Status indicators pair micro-typography (\`label-sm\`, uppercase Latin/standard Thai) with calibrated tint-to-border pairings:

\- Padding is strictly \`2px 8px\` with \`rounded\` (4px).

\- Status badges feature an internal 6px dot indicator: Amber for 'รอตรวจ', Rose for 'ขอแก้', Emerald for 'ผ่าน', Indigo for 'ลงแล้ว', Slate for 'ร่าง'.

\- Brand badges (FutureSkill / SkillPass) display solid subtle tint fills with brand typography.

&nbsp;

\#\#\# Social Caption Review Cards

\- White \`\#FFFFFF\` card bounded by 1px \`\#E2E8F0\` with \`rounded-lg\` (8px).

\- Internal layout: Top metadata strip containing Brand chip, Channel icon (Facebook Blue \`\#1D4ED8\`), Post Type, Target Date, and Status pill.

\- Content zone: Thai caption container with \`body-lg\` formatting, preserving line breaks, hashtags highlighted in \`\#4F46E5\`, and emoji scaling parity.

\- Footer: Word counter, character limit bar, reviewer assigned avatar stack, and fast status toggles.

&nbsp;

\#\#\# Version History Timeline

\- Vertical 2px line in \`\#E2E8F0\` positioned along the left rail.

\- Version nodes: 8px solid dots colored by status event.

\- Diffs rendered Notion-style: Additions wrapped in \`\#DCFCE7\` with green text; deletions highlighted with \`\#FEE2E2\` and strikethrough. Thai tone mark deletions keep the base consonant highlighted to preserve grammatical context.

&nbsp;

\#\#\# Form Inputs & Textareas

\- Base \`\#FFFFFF\` background, 1px \`\#CBD5E1\` border, 4px corner radius, inset text padding of 8px 12px.

\- Focus state: Border transitions to \`\#4F46E5\` with \`0 0 0 1px \#4F46E5\`. Error state switches border to \`\#E11D48\`.
